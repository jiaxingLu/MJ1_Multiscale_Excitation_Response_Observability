# Publication Scope

This repository is a curated public release of MERO v0.1.

## Included

- Frozen, English-only derived numerical tables used in the v0.1 conclusions.
- Evidence-graded claim matrix.
- Future experiment matrix.
- Public v0.1 closeout documentation.
- Reproducible figures and figure-generation scripts to be added before release.
- Final README to be co-designed after the figures are frozen.

## Not included

- Local absolute paths.
- Private working directories.
- Historical source filenames containing personal or non-English path information.
- Bilingual working scripts.
- Local audit artifacts that contain machine-specific paths.
- Raw source-project copies.

## Evidence policy

The public repository does not rewrite the scientific conclusions of the frozen
local MERO v0.1 archive. Public tables are curated English-only views of frozen
results.

The following boundaries remain active:

- no independent replication;
- no strict physical frequency causality;
- no strict physical amplitude causality;
- no cross-cell generalization;
- no cross-temperature generalization;
- no universal optimal-frequency claim;
- no small-signal EIS impedance claim.

## Version boundary

MERO v0.1 ends at:

Excite -> Observe -> Identify -> Estimate

The planned PyBaMM electrochemical-state bridge will be a post-v0.1 extension
and will add mechanism-oriented interpretation without rewriting v0.1 evidence.
